CHANGI JEWEL — пакет для GitHub Pages

КАК ОПУБЛИКОВАТЬ БЕСПЛАТНО:
1. Войди на https://github.com/ и создай аккаунт, если его ещё нет.
2. Нажми New repository (создать репозиторий).
3. Назови репозиторий: changi-jewel
4. Выбери Public и нажми Create repository.
5. Нажми Add file → Upload files.
6. Распакуй этот ZIP на телефоне/компьютере и загрузи ВСЁ содержимое папки в корень репозитория: index.html, manifest.webmanifest, sw.js, папку icons и .nojekyll.
7. Нажми Commit changes.
8. Открой Settings → Pages.
9. В разделе Build and deployment выбери Deploy from a branch.
10. Branch: main; Folder: /(root). Нажми Save.
11. Подожди немного. Ссылка будет иметь вид:
    https://ТВОЙ-ЛОГИН.github.io/changi-jewel/

УСТАНОВКА НА ANDROID:
1. Открой полученную ссылку в Chrome.
2. Нажми ⋮ → «Установить приложение» (или «Добавить на главный экран»).
3. Запускай CHANGI JEWEL с нового значка.

ВАЖНО:
- Это PWA, а не APK.
- Для публикации GitHub Pages нужен интернет.
- При первом запуске игры нужен интернет для загрузки библиотеки Three.js; затем основные файлы приложения сохраняются в кэш.
- Если изменишь файлы игры, снова загрузи их в репозиторий и подтверди изменения.
